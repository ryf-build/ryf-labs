# Visual Capture Checklist

Mermaidで説明できる構造図は本文へ埋め込みます。一方、Studio/Creator HubのUIは変化するため、**出版直前の現行画面を実際に撮る**ものとして分離します。

## 優先度A

1. Roblox Studio: Explorer / Properties / Output
2. Script / LocalScript / ModuleScriptを置く場所
3. `ReplicatedStorage/Shared`, `ServerScriptService`, `StarterPlayerScripts`の完成tree
4. `Coin` tag / Attribute
5. Phone EmulatorでCoin Rush UI
6. Server & Clientsで2 Clientが同じCoinへ近づく場面
7. Creator Hub: Developer Product ID
8. Creator Hub: Pass ID
9. Analytics dashboard: Retention / Funnel入口
10. Publishing / Access設定
11. DataStore load/save Output
12. Network / performance確認

## 優先度B

13. Demo World初期状態
14. Magnet Lv0 / Lv1比較
15. Zone2解除前後
16. Developer Product promptとCustom UIの価格一致
17. Release GateのEvidence例
18. Incident timelineのLog例

## Capture rule

- 1枚の注釈は1〜3個
- 最新Studio / Creator Hubで撮る
- Test account / UserId / revenueなど機微情報をマスク
- 操作前と結果を分けた方が理解しやすければ別画像にする
- UIが古くなったら本文より先に更新対象として扱う
